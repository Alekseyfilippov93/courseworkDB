# Анализ Вакансий с HeadHunter (HH.ru)

### Описание Проекта

Эта программа — ваш инструмент для сбора и анализа вакансий с сайта HH.ru.

**Суть:**
1.  Программа заходит на HeadHunter (через API).
2.  Собирает данные о вакансиях 10 крупных компаний.
3.  Сохраняет эти данные в базу **PostgreSQL**.
4.  Выводит готовую аналитику (средняя зарплата, самые высокооплачиваемые вакансии, поиск по ключевому слову).

### Требования к Запуску

Для работы программы нужно:
1.  **Python 3.12** (или совместимая версия).
2.  **Poetry** (менеджер зависимостей).
3.  Запущенный сервер **PostgreSQL** (для хранения данных).

### 🚀 Инструкция по Запуску

#### Установка Зависимостей

Откройте Терминал в PyCharm и выполните команду, чтобы установить все нужные библиотеки:

poetry install

### Настройка Пароля (.env)

#### config/.env
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=YOUR_PASSWORD
DB_HOST=localhost
DB_PORT=5432
API_URL_HH=[https://api.hh.ru](https://api.hh.ru)
API_USER_AGENT=CourseworkDBManager (Ваш емайл)

### Запуск Программы

python src/main.py

Что будет выполнено: 
Программа автоматически создаст базу данных, заполнит её данными и выведет результаты аналитических запросов.
